# Vastraa size inventory update

- Product detail now supports size selection.
- Sarees default to Free Size; stitched garments support XS/S/M/L/XL/XXL, with 3XL available in admin.
- Admin Add Product and Edit Product include size-wise stock.
- Existing products can be upgraded from Admin > Manage Products > Initialize Sizes.
- Cart stores the selected size as a separate cart line and shows size + quantity.
- Home/product cards now send shoppers to Product Detail to choose a size instead of silently adding a default size.
- Desktop category navigation uses hover/focus mega menus; mobile uses the hamburger drawer.
